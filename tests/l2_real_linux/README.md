# L2 real Linux user-service upgrade

`l2_real_linux_r0_to_r1` is one focused integration test. It is not an L3 release journey or a substitute for L3. First execution is gated on L1 passing on the published L0 library for the relevant candidate. Do not push a `venue/` ref or dispatch the test before the manager records that prerequisite.

The test authenticates the checked-in frozen R0 bootstrap, provenance and manifest against the existing journey verifier, and validates the immutable App checkout, manifest, bootstrap hashes and candidate Agent/Runtime pins. It installs R0 using its captured bootstrap and real `systemd --user`; verifies the manager's FragmentPath and an active R0 unit naming the selected version and `Restart=always`; writes a project, timeline, preferences and content object through the installed R0 workspace API; then performs the candidate's shipped update. It checks the selected candidate and real active service, owner replacement, the same realm, the four semantic values and completed candidate schema migration. For each version it checks that a nonblocking exclusive OS flock on the actual `owner.lock` is busy while the service is running, free after systemd stops it, and busy after restart, using the same device/inode through each stop/start. The test retains unit definitions and observations. It deliberately does not claim broad C5 transaction coverage, worker drain, rollback, other platforms, or L3 proof.

`run.sh` is limited to a disposable GitHub-hosted Ubuntu VM and nonzero UID. It establishes a real logged-in user manager (systemd >= 254), supplies an isolated unit path to that manager, proves discovery and execution with a real oneshot unit, and restores the manager and original linger setting in an EXIT trap. It refuses an existing unit, drop-in or run root. The runner test has a 45-minute outer timeout; the manager operations and cleanup are bounded. Logs, test JSON, service journal, per-command inner exits, setup/test and cleanup exits are retained in `l2-results/`. A timeout, missing result, incomplete collection, failed cleanup or absent inner exit is not a pass.
