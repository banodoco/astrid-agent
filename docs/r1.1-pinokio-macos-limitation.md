# R1.1 macOS Pinokio no-force limitation

The macOS row refuses at the `install` stage before invoking the launcher. The
frozen Pinokio candidate is `3a6a98ae251ca126505245286e2d3e760f4348e9`.
Its `pinokio/start.js:12` uses the serve session from
`pinokio/lib.js:355-359`. During that session,
`pinokio/session.mjs:370` runs a status probe, which calls `terminate` at
`pinokio/session.mjs:255`. On macOS, `pinokio/session.mjs:290` sends
`SIGKILL` to the probe's process group even when the direct child has closed.
The local installation path also enters a build session via
`pinokio/install-local.js:11`.

The row's host card forbids force-kill anywhere in the row. Until the pinned
launcher and the host rule are reconciled, the runner returns one failed stage
and performs no installation, session start, stop, process signaling, or cleanup.
This is a limitation, not evidence that the R1.1 macOS row passed.
