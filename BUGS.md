# Pack discovery findings

- **R5, root cause and repair:** cache fingerprinting previously decided payload selection from manifest visibility alone, before canonical admission, source schema quarantine, external manifest isolation, or duplicate handling. It therefore opened payloads belonging to unadmitted candidates. Fingerprinting now retains candidate manifest/name inputs and uses canonical loader admission plus the scanner's source/external selection rules before descending into payloads. This keeps selected payload edits cache-invalidating while quarantined, hidden, malformed, incompatible, duplicate, and scanner-ignored payloads remain unopened. A source candidate that becomes admissible changes the manifest fingerprint and triggers a rescan.
