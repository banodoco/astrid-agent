# Pack discovery findings

- **R5, repaired selected-input boundary:** r4 fingerprinting called full canonical admission before checking visibility. Canonical admission itself opened and hashed declared resources, so the earlier claim that rejected payloads stayed unopened was inaccurate. Discovery now uses canonical metadata/path preflight for visibility and metadata rejection, and fingerprints resource bytes only for roots returned by real full admission. Metadata/path failures are checked across all declarations before resource reads; descriptor identities are checked before hashing other resources. Hidden and metadata-rejected resources remain unopened on cold scans and warm lookups. Content rejection still requires reading the descriptor that establishes the error on a real scan; warm reuse observes its filesystem edit state without opening or hashing it. Manifest/schema bytes, path/type changes, rejected descriptor stat changes, visibility changes and selected content hashes invalidate reuse. External metadata discovery retains its existing v2/compatibility behavior; the strict loader scanner's compatibility quarantine runs before resource reads. This is not evidence that every discovery API enforces API compatibility.

- **R5, repaired strict-source invalidation:** r4 omitted source symlink children from cache identity, allowing a warm empty result to hide a newly symlinked pack. The fingerprint now records the link name/type/target and the directory/manifest metadata consulted by the source scanner, without traversing or reading target payloads. Addition, removal, retargeting and target manifest presence changes reach the real strict scanner, which continues to own refusal.

- **R4, remaining qualification limit:** focused cache tests isolate filesystem roots and managed inventory with fixtures; they do not qualify installed or remote inventory composition. The existing real local-Git provisioning/discovery test and real support composition test provide local coverage only. Installed-artifact qualification remains unproven in this change.
